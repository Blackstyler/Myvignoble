Comment publier votre site gratuitement ?

3 plateformes simples et sans frais d'hébergement

1 Netlify Drop (Le plus rapide - Sans code)
  1. Téléchargez votre fichier index.html depuis CréaSite Studio.
  2. Mettez ce fichier dans un dossier sur votre ordinateur.
  3. Rendez-vous sur app.netlify.com/drop.
  4. Glissez-déposez le dossier. Votre site est en ligne instantanément avec un lien HTTPS gratuit !
2 GitHub Pages (Idéal pour les développeurs)
  1. Créez un dépôt public sur GitHub.com.
  2. Importez votre fichier index.html à la racine du dépôt.
  3. Allez dans Settings > Pages et sélectionnez la branche principale.
  4. Votre site sera accessible sur votre-pseudo.github.io/mon-site.
3 Vercel Hosting

Glissez votre projet sur Vercel.com pour bénéficier d'un réseau CDN ultra-rapide et sécurisé sans débourser un centime.
